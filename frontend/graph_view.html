Quantitative Agent

Always runs. Pure math — RSI, MACD, EMA, probability bands. Cheapest token cost.

Academic Agent

Conditional. Fires when RSI is extreme (>65 / <35) or trend is clearly directional.

Geopolitical Agent

Conditional. Fires only when news feed has meaningful content (>80 chars).

User Insight Agent

Conditional. Fires only when you've submitted a manual insight this session.

Orchestrator (decision node)

Always runs last. Synthesizes only reports that actually ran this cycle.
